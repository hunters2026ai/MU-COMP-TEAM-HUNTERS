## 1. APIs and services

| Service | What we use it for | Where |
|---|---|---|
| **WhatsApp Cloud API** (Meta Graph API v23.0) | Receiving rider messages (webhook), downloading media, sending text, buttons, lists, voice notes and PDFs | `n8n/build.mjs` (all WhatsApp nodes) |
| **Anthropic Claude API** (`claude-opus-5-5`) | Reading screenshots into structured data, writing replies in the rider's language, understanding voice answers, drafting the complaint letter | `n8n/build.mjs` (prompts P1–P6), `docs/CLAUDE_PROMPTS.md` |
| **Sarvam AI** — text-to-speech (`bulbul:v3`) and speech-to-text (`saaras:v4`) | Telugu, Hindi and Kannada voice replies; transcribing riders' voice notes | `n8n/build.mjs` (SPEAK, TRANSCRIBE), `demo/gen_audio.mjs` |
| **Supabase** (Postgres via PostgREST, Storage) | Riders, evidence register, screens, cases, interviews, rate cards; private storage of original screenshots | `n8n/schema.sql`, all `supa` nodes |
| **Google Drive API** | Converting the complaint letter (HTML) into a Google Doc and exporting it as PDF | `n8n/build.mjs` (PETITION) |
| **n8n** (self-hosted instance provided to us, v2.47.7) and its **public REST API** | Runs every workflow; our build script creates and publishes the workflows through the API | `n8n/build.mjs` |

## 2. Open-source libraries and runtimes

| Item | Licence | Use |

**No third-party npm packages are installed.** The SHA-256 used to fingerprint evidence inside n8n is written by us (`n8n/rules.js`) and tested against Node's built-in `crypto` (`n8n/rules.test.js`).

## 3. Templates

**None.** The n8n workflows, rules engine, database schema and demo page (`demo/index.html`, a WhatsApp-style chat built with our own HTML/CSS/JS) were written for this project. No UI kits, starter templates or n8n template-library workflows were used.

## 4. Datasets and reference material

**No external dataset is used by the product.**

- **Demo data is synthetic:** 40 demo riders and one rate card at "ZipDrop Madhapur" are generated by `n8n/schema.sql` and marked `synthetic = true`. "ZipDrop" is a fictional platform; the mock screenshots were made by the team.
- **Law texts** used to write the rules engine:
  - Karnataka Platform Based Gig Workers (Social Security and Welfare) Act 2025 (Act 72 of 2025), PRS India copy
  - Telangana Platform Based Gig Workers (Registration, Social Security and Welfare) Act 2026 (Act 21 of 2026), PRS India copy
  - Telangana Platform Based Gig Workers Rules 2026 (G.O.Ms.No.18), via secondary reporting (marked "unverified" in the code)
- **Statistics quoted in the pitch** come from published sources listed in `docs/PROOF_RIDER_PLAN.md` §10 (TechCrunch 2023, VVGNLI study via Business Standard, *Prisoners on Wheels?* report by PAIGAM + IFAT, Internet Research Lab arXiv 2609.13178, NITI Aayog 2022).
